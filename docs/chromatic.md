# Fixed-geometry energy scans

The [chromatic imaging guide](source/chromatic.rst) is the maintained user
guide and is included in the Sphinx documentation. It covers the ASTRA/CUDA
API, fixed and refocused scans, integration controls, model limits and tests.

API documentation is generated from `darkmod.chromatic`,
`darkmod.chromatic_imaging` and `darkmod.chromatic_gpu` in the Sphinx index.
